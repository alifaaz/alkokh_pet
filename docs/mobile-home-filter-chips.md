# Mobile Home Filter Chips

Filter chips are managed with `Mobile Home Filter` records, then Products link to one filter.

The mobile app still uses:

```http
GET /api/method/pet_app.api.mobile.catalog.home_v2?locale=en&filter_key=dog
```

For authenticated admin/frontend testing of the saved draft before Publish:

```http
GET /api/method/pet_app.api.mobile.catalog.home_draft?locale=en&filter_key=dog
```

`home_draft` returns the saved draft rendered in the same home block shape, with `preview: true` and `draft_revision`. It is not public/guest.

## Resource: Mobile Home Filter

```text
/api/resource/Mobile%20Home%20Filter
```

## Fields

| Field | Type | Required | Notes |
|---|---|---|---|
| `filter_key` | string | Yes | Unique kebab-case key, e.g. `dog`, `cat-food`, `puppy`. |
| `enabled` | number | Yes | `1` enabled, `0` disabled. |
| `label_en` | string | Yes | English chip label. |
| `label_ar` | string | Yes | Arabic chip label. |
| `display_order` | number | Yes | Order after `all`. |

## Create Filter

```json
{
  "filter_key": "dog",
  "enabled": 1,
  "label_en": "Dog",
  "label_ar": "كلاب",
  "display_order": 20
}
```

## Product Link

Each Product gets:

```text
mobile_home_filter -> Link Mobile Home Filter
```

Example Product update:

```json
{
  "mobile_home_filter": "dog"
}
```

## Builder Behavior

- Frontend should not manually edit `draft.filters[].product_ids`.
- Builder reads filters from backend.
- Product membership comes from `Product.mobile_home_filter`.
- `all` is always generated by backend.
- Publish snapshots resolved Product IDs.
- `home_draft` reads the current saved draft.
- `home_v2` reads the active published snapshot, or legacy fallback when nothing is published.

## Mobile Behavior

1. Render chips from `home_v2.data.filters`.
2. Default selected chip: `all`.
3. On chip tap, reload home:

```http
GET /api/method/pet_app.api.mobile.catalog.home_v2?locale=en&filter_key=dog
```

4. For Show All:

```http
GET /api/method/pet_app.api.mobile.catalog.home_block_v2?block_id=featured-products&locale=en&filter_key=dog
```

## Rules

- Disabled filters do not appear in published home.
- One Product can belong to one custom filter.
- Products without `mobile_home_filter` appear under `all` only.
- Banners, categories, and brands ignore filter chips.
- Product lists only respect chips when `respects_filter: true`.
