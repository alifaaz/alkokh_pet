Welcome to the Pet Management API documentation. This API allows you to manage pets, track medical records, handle adoptions, and generate statistics.

Endpoint Format: {base_url}/pet_app.api.pet_api.{function_name}

Example: /api/method/pet_app.api.pet_api.get_available_pets

🔐 Authentication & CSRF Protection

This API uses Frappe's token-based authentication with automatic CSRF protection.

Step 1: Authenticate
  1. Generate API keys from your Frappe user profile
  2. Click the "Authorize" button in the Swagger UI below
  3. Enter your credentials in format: token <api_key>:<api_secret>
  4. Example: token abc123:xyz789
Step 2: CSRF Token (Automatic)

✅ Swagger UI automatically handles CSRF tokens! After you authenticate:

  • GET requests work immediately (no CSRF needed)
  • POST/PUT/DELETE requests automatically fetch and include CSRF tokens
  • Watch the browser console for CSRF token status messages

For Manual API Calls:

  1. First, call GET /pet_app.api.pet_api.get_csrf_token
  2. Include the token in X-Frappe-CSRF-Token header for POST/PUT/DELETE requests

Note: Some endpoints are public and don't require authentication (marked with an open lock icon 🔓)
